# Каталог промтов

Статический каталог официально опубликованных промтов для LLM. Живая версия: **https://xal1fat.github.io/prompt-catalog/**

518 записей, 4,76 млн знаков. Открывается и локально — двойным кликом по `index.html`, без сервера и сборки.

## Разделы

| Раздел | Источник | Статус |
|---|---|---|
| Системные промты Claude, 49 версий | `platform.claude.com/docs/en/release-notes/system-prompts` | Официальный |
| OpenAI Cookbook, 107 примеров | `github.com/openai/openai-cookbook` | Официальный |
| Google, 50 примеров | `ai.google.dev` + `google-gemini/cookbook` | Официальный |
| Microsoft PnP, 119 сэмплов | `github.com/pnp/copilot-prompts` | Сообщество PnP |
| Утечки, 195 текстов | `x1xhlol/...`, `LouisShark/chatgpt_system_prompt` | Неофициальный |

Anthropic официально публикует системные промты каждой модели — видно, как менялось поведение Claude от Haiku 3 до Opus 5.5.

## Что можно делать

- Искать по названию, вендору, коллекции и тексту; ссылка с поиском шарится (`?q=sonnet`).
- Фильтровать по типу записи, вендору и теме.
- Копировать промт целиком и ссылаться на карточку (`#/p/<id>`).

## Принципы

- Промты приведены **дословно**: не переписаны, не переведены, не «улучшены». Русский — только в описании.
- У каждой записи есть первоисточник; все 358 уникальных ссылок проверены скриптом (код 200 + сверка текста).
- Утечки отделены: свой фильтр, плашка и предупреждение в карточке. За официальные они не выдаются.

## Структура

```
index.html      страница
styles.css      оформление
app.js          поиск, фильтры, просмотр, копирование (vanilla JS)
data/
  prompts.js        518 записей (утечки без текста)
  leaks-index.js    метаданные утечек
  leaks-text.js     3,8 МБ текстов утечек, грузятся по клику
.nojekyll       отключает Jekyll на GitHub Pages
```

Данные подключены как `<script>`, а не через `fetch` — поэтому сайт работает по `file://`.

## Чего здесь нет

- **Официальных системных промтов ChatGPT** — OpenAI их не публикует, всё существующее в сети является утечками.
- **Prompt Library Anthropic** (65 промтов 2024 года) — библиотека снята с сайта, веб-архив отдаёт оболочки без текста, восстановить целиком не удалось.
