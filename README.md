# Указатель промтов

Русский указатель официально опубликованных промтов для LLM. Живая версия: **https://xal1fat.github.io/prompt-catalog/**

518 записей, 4,76 млн знаков. Открывается и локально — двойным кликом по `index.html`, без сервера и сборки.

## Что переведено, а что нет

Русские: интерфейс, названия записей, названия коллекций, пояснения «что это и откуда».
Оригинальные: **тексты промтов**. Они не переводились и не редактировались — это дословные цитаты. В карточке под названием стоит строка «в источнике: …» с оригинальным заголовком, чтобы запись можно было найти на GitHub.

## Как устроен интерфейс

Печатный указатель: слева оглавление с точечными выносками и счётчиками, справа — строки каталога с шифром (`ANT-SYS` — вендор и тема), серифным названием, точечной выноской и размером. Карточка открывается как отдельный «лист» с рамкой, полем на полях и блоком текста в моноширинном наборе.

- Поиск по названию, вендору, коллекции и тексту; ссылка с поиском шарится (`?q=встреч`).
- Фильтры по разделу, вендору и теме; счётчики пересчитываются.
- Копирование промта целиком и ссылка на карточку (`#/p/<id>`).

## Принципы

- Промты приведены дословно: не переписаны, не сокращены, не «улучшены».
- У каждой записи есть первоисточник; все 358 уникальных ссылок проверены скриптом (код 200 + сверка текста).
- Утечки отделены: свой фильтр, цвет и предупреждение в карточке.
- Описания собраны из метаданных источника, без придуманных утверждений.

## Структура

```
index.html      страница
styles.css      оформление (светлая бумага, сериф, точечные выноски)
app.js          поиск, фильтры, просмотр, копирование (vanilla JS)
data/
  prompts.js        518 записей (утечки без текста)
  leaks-index.js    метаданные утечек
  leaks-text.js     3,8 МБ текстов утечек, грузятся по клику
.nojekyll       отключает Jekyll на GitHub Pages
```

Данные подключены как `<script>`, а не через `fetch` — поэтому сайт работает по `file://`.

## Чего здесь нет

- **Официальных системных промтов ChatGPT** — OpenAI их не публикует, всё существующее в сети является утечками.
- **Prompt Library Anthropic** (65 промтов 2024 года) — библиотека снята с сайта, веб-архив отдаёт оболочки без текста, восстановить целиком не удалось.
