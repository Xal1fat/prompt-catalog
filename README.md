# Каталог промтов

Статический каталог официально опубликованных промтов для LLM: системные промты Claude, библиотека Anthropic, примеры из OpenAI Cookbook, документация и cookbook Google, сэмплы Microsoft PnP. Отдельным разделом — системные промты продуктов, которые вендоры не публиковали (помечены как «Утечка»).

Сайт без сборки и зависимостей: открывается двойным кликом (`index.html`), кладётся на любой статический хостинг.

## Что внутри

| Раздел | Что это | Статус |
|---|---|---|
| Системные промты Claude | Дословные системные промты, которые Anthropic публикует для каждой версии модели на `platform.claude.com` | Официальный |
| Библиотека промтов Anthropic | Классическая Prompt Library, восстановленная из веб-архива (живая версия снята с сайта) | Архив вендора |
| OpenAI Cookbook | Примеры промтов из официальных гайдов OpenAI (GPT-5, Codex, Realtime, Sora и др.) | Официальный |
| Google | Примеры из документации Gemini и официального cookbook | Официальный |
| Microsoft PnP | Сэмплы из `github.com/pnp/copilot-prompts` — официальная программа Microsoft, промты сообщества | Сообщество PnP |
| Утечки | Системные промты продуктов (Cursor, Devin, Claude Code, ChatGPT-агент и др.) из публичных репозиториев | Неофициальный |

## Структура

```
index.html      статическая страница
styles.css      оформление
app.js          поиск, фильтры, просмотр, копирование (vanilla JS)
data/
  prompts.js        основной массив записей (window.PROMPTS)
  leaks-index.js    метаданные раздела «Утечки»
  leaks-text.js     полные тексты утечек (~3.7 МБ), грузятся по требованию
.nojekyll       отключает Jekyll на GitHub Pages
```

Данные подключены как `<script>`, а не через `fetch` — поэтому сайт работает и по `file://`, без локального сервера.

## Принципы

- Промты приведены **дословно**. Мы не переписываем, не «улучшаем» и не переводим текст промта — только добавляем русское описание и категорию.
- У каждой записи есть ссылка на первоисточник и дата проверки.
- Утечки отделены от официальных публикаций и подписаны явно: вендор эти тексты не публиковал.
- `scripts/validate.py` в исходном проекте проверяет ссылки и наличие текста в источнике.

## Обновление

Тексты собраны 31 октября 2026 года. Чтобы обновить — перезапустите извлекатели в исходном проекте (`scripts/fetch_*.py`), затем `scripts/build.py`.
